# 自动语义推断阈值

「BIM翻模大师」在没有项目级图层规则表时使用的判据。与代码 `RevitModeler.Core/LayerSemantics.cs` 保持一致。

## 图层名关键词（命中即高置信）

| 类别 | 中文关键词 | 英文关键词 | 置信度 |
|---|---|---|---|
| 柱 | 柱 | column | 0.92 |
| 门 | 门 | door | 0.90 |
| 窗 | 窗 | window | 0.90 |
| 墙 | 墙 | wall | 0.90 |
| 楼板 | 楼板 | floor / slab | 0.88~0.92 |
| 地面/天花 | 地面 / 天花 | finish / ceiling | 0.80 |
| 家具 | 家具 / 家俱 | furniture | 0.90 |
| 标注 | 标注 / 文字 / 轴线 | dim / text / axis | 0.85~0.95 |

## 几何特征推断

| 特征 | 推断 | 置信度 |
|---|---|---|
| 闭合多段线，面积 ≥1㎡ | 楼板 | 0.72 |
| 闭合多段线，面积 <1㎡ | 楼板（待复核）| 0.55 |
| 线段 ≥600mm + 平行近邻（20~400mm）| 墙（双线墙）| 0.72 |
| 线段 ≥600mm，无平行近邻 | 墙占位（待复核）| 0.45 |
| 圆弧 | 门开启线（待复核）| 0.45 |
| 圆 | 柱（待复核）| 0.40 |
| 块名含关键词 | 对应族类 | 0.55~0.75 |

## 处理分档

- ≥0.7 高置信：直接建模
- 0.4~0.7 中置信：先占位建模，标记待图像复核
- <0.4 低置信：不建模，列入问题清单
